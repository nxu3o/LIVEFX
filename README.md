# LIVEFX

### Bring the stage to your audio.

오디오 파일에 공간감과 리버브를 적용해 **콘서트 · 아레나 · 스타디움 같은 사운드**를 만들어주는 Windows 오디오 효과 프로그램입니다.

## 🎛️ Features

| Feature     | Description                                                            |
| ----------- | ---------------------------------------------------------------------- |
| **Presets** | Concert · Arena · Stadium · Live House · Theater · Small Hall          |
| **Effects** | Room Size · Early Reflection · Reverb · Decay · Stereo Width · Wet/Dry |
| **Formats** | MP3 · WAV · FLAC · OGG · AAC · M4A · MP4 · MKV · MOV                   |
| **Player**  | 재생 · 일시정지 · 정지 · 탐색 · 볼륨                                               |
| **Export**  | WAV · FLAC · OGG · MP3 · MP4                                           |
| **Update**  | 자동 업데이트 지원                                                             |

## 📥 Installation

**Windows 10 / 11 지원**

`LIVEFX-Setup-X.X.X.exe`를 다운로드한 후 실행하여 설치합니다.

설치가 완료되면 **LIVEFX**를 실행하세요.

> MP3/MP4 Export 및 일부 미디어 형식 처리를 위해 **FFmpeg**가 필요합니다.

## ⚙️ Usage

**OPEN** → 파일 선택 → **Preset 선택** → 효과 조절 → **PLAY** → **EXPORT**
